# Radar de aperturas comerciales — Zona Norte GBA

Sitio estático que lista locales comerciales recién abiertos o por abrir en zona norte del Gran Buenos Aires,
detectados automáticamente desde fuentes públicas (OpenStreetMap, medios locales, directorios de shoppings y
buscadores de sucursales de cadenas). Se actualiza todos los días con GitHub Actions.

> Documentación completa en preparación. Ver `docs/ARCA.md` para la evaluación de ARCA.
